# Rever One – sito

Pagina unica statica (HTML, immagini, video, font). Nessuna installazione richiesta.

- Pagina: `index.html`
- Immagini: `img/` · Video: `video/` · Font Montserrat ospitato in locale: `fonts/` (licenza SIL OFL)
- Indirizzo email: cercare `const EMAIL` in `index.html` e sostituire `[EMAIL RICHIESTE]`.
- Modulo di iscrizione: incollare in `const SIGNUP_URL` l indirizzo "action" del modulo Brevo.
- Al lancio: togliere la riga `<meta name="robots" content="noindex,nofollow">`.
